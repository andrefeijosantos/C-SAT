# FSU CNF Dataset

This dataset contains a collection of Boolean formulas in Conjunctive Normal Form (CNF), originally obtained from the Florida State University CNF Data Files archive:

🔗 https://people.sc.fsu.edu/~jburkardt/data/cnf/cnf.html

## License

The dataset is publicly available. Please refer to the original [FSU CNF Data Page](https://people.sc.fsu.edu/~jburkardt/data/cnf/cnf.html) for attribution or usage notes.
